# Cálculo del total de una compra

**Estudiante:** Poleth Avila

## Descripción

Este proyecto consiste en desarrollar una función en Python que permite calcular el total de una compra a partir del precio de un producto y la cantidad adquirida.

## Funcionamiento

La función recibe dos parámetros:
- Precio del producto.
- Cantidad de productos.

Luego realiza la multiplicación del precio por la cantidad y devuelve el total de la compra.
